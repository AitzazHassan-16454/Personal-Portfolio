Case study — Boson Studio

Nova AI
Chatbot Platform

Enterprise conversational agents often falter during provider outages and struggle with rich document formats. I engineered Nova AI: a multi-modal conversational platform with sub-second token streaming, real-time Web Audio visualizers, and dynamic failover across Gemini, OpenAI, Groq, and Anthropic.

01 — The brief Overcoming single-provider fragility and multi-modal blind spots.

Standard chatbots are tied to a single foundation model provider. When OpenAI or Anthropic experiences rate limiting, latency spikes, or service degradation, end-users face broken chats and lost context.

Additionally, users needed to upload complex PDFs, technical diagrams, and contracts, expecting the model to inspect tabular data and visual layouts accurately while supporting natural voice conversations with fluid speech visualizers.

The challenge was to architect a provider-agnostic multi-agent engine in Laravel 12 and Vue 3 that normalizes responses, detects API degradation in milliseconds, switches model providers on the fly, and exposes low-latency voice and vision endpoints.

02 — What I built Multi-provider failover, multimodal vision pipelines, and Web Audio API integration.

Nova AI coordinates diverse foundation models through a unified backend facade, rendering fluid conversational experiences in Vue 3.

  • Multi-Provider LLM Failover Engine — Unified adapter interfacing Gemini SDK, OpenAI API, Groq, and Anthropic Claude. Automatic fallback reroutes traffic in under 350ms upon provider errors or rate limits.
  • Multimodal Document & Vision Parsing — Ingests PDFs, images, and schematics. Converts visual content into structured embeddings and vision model prompts for deep factual inspection.
  • Web Audio API Speech Visualizer — High-framerate browser audio frequency visualizer providing real-time waveform feedback during speech input and synthesis.
  • Sub-Second Server-Sent Events — Event-driven token streaming pipeline ensuring conversational velocity remains snappy regardless of underlying model size.

The interface supports split-view document inspection, markdown syntax highlighting, and interactive parameter tweaking (temperature, system instructions, active model selection).

03 — The hard part Normalizing heterogeneous LLM streams and 60fps audio synchronization.

Unified stream normalization across 4 providers

Gemini, OpenAI, Groq, and Anthropic have radically different SSE event formats, token chunk structures, and error response payloads. I created an abstraction pipeline in Laravel that wraps each provider SDK into a standardized stream protocol. When a primary provider fails mid-stream, the engine preserves already-emitted tokens and requests the continuation from the secondary provider.

60fps Web Audio API waveform visualization

Hooking microphone streams directly into Vue 3 reactivity can trigger redundant component re-renders, leading to visual stutter. I decoupled the AudioContext AnalyserNode from Vue state, running the Fast Fourier Transform (FFT) analysis loop inside an independent requestAnimationFrame canvas renderer for perfectly smooth 60fps animations.

High-fidelity PDF and diagram extraction

Multi-column documents and technical schematics often break naive OCR extraction. I built an extraction workflow that extracts both text blocks and rasterized image fragments, feeding them to multimodal Gemini and OpenAI vision endpoints for complete spatial comprehension.
