01 — The brief Breaking out of rigid SQL fulltext search and static shopping carts.

Online shoppers rarely search with exact SKU names or database keywords. Queries like "breathable trail running shoes for wet weather" traditionally returned zero results in standard catalog searches, driving frustration and cart abandonment.

Furthermore, recommendation systems were static and unresponsive to ongoing shopper context. Shoppers were forced to browse separate categories instead of having an assistant suggest compatible accessories, check live warehouse inventory, and bundle discounts automatically.

The project required a complete rebuild: a vector-native product engine, conversational agent tool-calling for instant cart mutations, and rock-solid test automation with Pest v4 across all revenue-critical pathways.

02 — What I built Cosine similarity search, autonomous shopping agents, and bulletproof Pest v4 tests.

Built with Laravel and Vue 3 on Inertia.js, the platform offers sub-50ms catalog retrieval and frictionless single-page navigation.

  • Vector Semantic Search — Embeds product descriptions, attributes, and tags into high-dimensional vectors, executing cosine similarity matching to return intent-aligned products even with misspelled or descriptive queries.
  • Autonomous Agent Tool-Calling — Equips AI shopping assistants with callable backend tools: inventory checks, real-time cart manipulation, discount code validation, and shipping cost estimation.
  • Reactive Vue 3 & Inertia Cart — Instantaneous cart drawer and checkout flow without full-page reloads, backed by optimistic UI updates and live stock reservation.
  • Pest v4 Automated Test Suite — End-to-end automated tests covering vector search accuracy, concurrent stock deductions, promotion logic, and payment processing.

Shoppers enjoy a seamless experience: they can search visually or conversationally, and items land directly in their cart through natural language prompts.

03 — The hard part Vector search latency under scale, and deterministic agent boundaries.

Sub-50ms Cosine Similarity Calculations

Evaluating high-dimensional dot products across tens of thousands of catalog items can saturate database CPU. I implemented a hybrid retrieval strategy: category and price filters narrow the candidate pool first, followed by rapid cosine similarity re-ranking in memory. Search latency stays consistently under 45ms.

Guarded Agent Tool Execution

Autonomous agents executing actions like "add to cart" or "apply discount" must never bypass business rules or mutate state with hallucinated inputs. I designed a tool-calling middleware that validates parameter schemas, verifies user permissions, checks warehouse inventory bounds, and locks item records during transactions.

Comprehensive Pest v4 Test Harness

Testing AI-driven workflows without hitting rate-limited external APIs or incurring per-test costs requires clean architecture. I authored mock vector providers and deterministic agent fixtures in Pest v4, enabling CI/CD pipelines to run full end-to-end test suites in seconds.
